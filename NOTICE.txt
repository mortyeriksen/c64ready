Ported / derived algorithms and model constants
================================================================================

reSID
    Copyright © 2010 Dag Lem <resid@nimrod.no>
    GNU General Public License, version 2 or later
    https://github.com/daglem/reSID

    The SID implementation is substantially a JavaScript translation of
    reSID: oscillator and waveform timing, the noise shift-register logic,
    the pipelined ADSR envelope generator, the measured combined-waveform
    lookup tables (OSC3 samplings of real 6581/8580 chips, embedded verbatim
    in src/sid-wavetables.js and, for the WASM engine, as the eight
    rust/sid/data/wave*.dat files — see rust/sid/data/README.md), the R-2R
    DAC models with subthreshold leakage (dac.cc), the transistor-level
    filter / mixer / nonlinear volume stage (filter8580new), the external RC
    filter, the SINC audio resampler (sid.cc), and SID data-bus readback. The
    combined-waveform sample data descends from chip samplings provided to
    reSID by Tibor Biczo, Andreas Boose and André Fachat (reSID THANKS).

    The port is pinned to reSID AS DISTRIBUTED IN VICE 3.10's modified
    src/resid tree (see the VICE entry below): some ported behaviors are
    VICE-team modifications that exist only there, e.g. the measured gradual
    TEST-bit fade of the noise shift register and the improved 8580 filter
    model compiled by VICE's default build. Exact upstream pin: the official
    VICE 3.10 source release, vice-3.10.tar.gz, sha256
    8e5bac18cbcb9f192380ad3ef881f8790f5b75c41d7b3da65d831985d864d6d1
    (https://downloads.sourceforge.net/project/vice-emu/releases/); every
    src/resid source file in that release carries the header
    "Copyright (C) 2010 Dag Lem" (voice.cc: 2004) with the GNU GPL
    "version 2 ... or (at your option) any later version" grant.

    reSID is GPL-2.0-or-later; it is conveyed here as part of this
    GPL-3.0-or-later project under the "any later version" grant, with all
    upstream copyright notices retained in the translated files.

    The engine ships in two additional forms beside the JavaScript
    translation (src/sid-voice.js, src/sid-filter.js, src/sid-worklet.js):
    a Rust translation of that JavaScript under rust/sid/, and the
    WebAssembly module compiled from it (embedded base64 in
    src/sid-wasm-blob.js; rebuilt reproducibly by rust/sid/build.sh with
    the toolchain pinned in rust/sid/rust-toolchain.toml). Both are
    derivative works of reSID as pinned above, conveyed under
    GPL-3.0-or-later; rust/sid/ is the corresponding source for the
    compiled module. The compiled module statically includes portions of
    the Rust standard library, licensed MIT OR Apache-2.0 and used here
    under the MIT option (MIT license text reproduced at the bottom of
    this file).

VICE — src/resid modifications and reSID wrapper conventions
    Copyright © The VICE Team
    GNU General Public License, version 2 or later
    https://vice-emu.sourceforge.io/

    The reSID tree this SID port translates from is VICE's modified copy
    (see the reSID entry above), so portions of the SID implementation
    derive from VICE-team modifications as well. The runtime conventions of
    VICE's reSID wrapper (src/sid/resid.cc: filter bias in mV/1000,
    resampler passband/gain percentages, output amplification
    clip(scale·x/2)) are followed so that output can be compared against
    headless VICE x64sc, this project's regression oracle.

VIC-II color palettes — "Pepto" and "Colodore"
    Measurement data by Philip Timmermann ("Pepto")
    https://www.pepto.de/projects/colorvic/  ·  https://www.colodore.com
    The two selectable VIC-II palettes embedded in src/vic2-tables.js
    reproduce pepto's published palette values.

Reference implementations and calibration sources  (not redistributed)
================================================================================

VICE
    Copyright © The VICE Team
    GNU General Public License, version 2 or later
    https://vice-emu.sourceforge.io/  ·  https://github.com/VICE-Team/svn-mirror
    Used as a behavioral reference, regression oracle and calibration source
    throughout. The GCR track-layout synthesis parameters in src/gcr.js
    (per-zone tail gaps and the 9-byte header-to-data gap) follow VICE's
    D64-to-GCR conversion so that each sector's GCR framing matches VICE's
    byte-for-byte. (The whole-track bitstream still differs: this project
    does not reproduce VICE's per-track skew rotation.) The power-on RAM
    pattern in src/memory.js (an 8-byte 00 00 FF FF FF FF 00 00 cycle) is
    VICE's default RAM initialisation, taken from a boot dump so demos that
    read uninitialised memory behave alike. This project does not distribute
    VICE binaries. For the PORTED code taken from VICE's
    modified src/resid tree and the wrapper conventions it follows, see the
    "VICE — src/resid modifications" entry in the SID section above.
